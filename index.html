QA POS Automation Macro v2.6.0

Suite portable de automatización de transacciones POS con macros
Plataforma: Windows POSReady / 10 / 11  |  Licencia: MIT  |  Autor: Efraín Cortez
Ejecutar / Ver Código en GitHub Descargas & Releases (.exe)
¿Qué es y qué hace?

Es una suite portable y modular creada para optimizar y automatizar la ejecución de transacciones complejas en terminales de Punto de Venta (POS) en entornos de retail y comercio.

Opera mediante emulación de teclado e inyección de eventos a nivel de sistema operativo con latencia ultra-baja, eliminando los errores humanos en pruebas manuales repetitivas y permitiendo ejecutar flujos continuos de venta, cobros, devoluciones y validaciones transaccionales. Además, cuenta con una interfaz retro inspirada en Windows Vista Aero Glass.

Tecnologías y Stack Utilizado
AutoHotkey v2.0 Windows API (Keystroke Injection) Windows Vista Aero Glass UI Oracle Xstore POS Omnipay Pasarelas Windows POSReady / Win 10 / Win 11
Capacidades y Flujos de Automatización
  • Emulación de baja latencia: Ejecución rápida y precisa de atajos de teclado y secuencias POS nativas.
  • Pruebas de estrés y regresión: Capacidad de disparar ráfagas transaccionales para validar la estabilidad del hardware y software de caja.
  • Flujos multitarjeta y anulación: Simulación de ventas con tarjetas de crédito/débito, cancelaciones y reintentos.
  • Portabilidad absoluta: No requiere instalación ni permisos de administrador complejos para correr en terminales POS.

QA Suite Xray v1.0

Estructuración y exportación inteligente de casos de prueba para Jira Xray
Integración: Atlassian Jira & Xray Test Management  |  Autor: Efraín Cortez
Ver Código Fuente en GitHub
¿Qué es y qué hace?

Es una aplicación de escritorio diseñada para preparar, redactar y organizar casos de prueba manuales de sistemas transaccionales como Oracle Xstore y pasarelas Omnipay, automatizando su conversión y exportación en un formato CSV normalizado listo para importarse directamente en Jira mediante la extensión Xray.

Resuelve el cuello de botella de tener que redactar manualmente los mismos pasos y adaptar los datos a la plantilla que exige Xray para cada historia de usuario, garantizando consistencia, eliminando duplicados y acelerando la fase de diseño de pruebas en un 70%.

Tecnologías y Stack Utilizado
Python Desktop App Atlassian Jira Software Xray Test Management CSV Normalized Data Engine Oracle Xstore POS Omnipay Gateway Integration
Beneficios y Características Principales
  • Estandarización automática: Genera pasos de prueba, datos de entrada y resultados esperados uniformes.
  • Validación previa: Comprueba que los campos mandatorios de Xray estén completos antes de generar el archivo final.
  • Cero modificación directa de Jira: Trabaja 100% en local para que el analista QA valide antes de importar.
  • Reducción de retrabajo: Reutilización ágil de plantillas para transacciones POS complejas.
Módulo: Generador CSV Jira/Xray Listo
